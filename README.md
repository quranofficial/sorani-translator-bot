# بۆتی وەرگێڕی کوردی سۆرانی (Telegram Bot)

بۆتێکی تەلەگرامە بە زمانی Python کە وەکو وەرگێڕ کار دەکات بۆ کوردی سۆرانی:

- **دەق** — هەر دەقێک بە هەر زمانێک بنێری، بە سۆرانی وەریدەگێڕێت.
- **فایل** — PDF، Word (docx)، PowerPoint (pptx)، TXT، SRT: وەرگێڕدراوەکە بە **هەمان جۆری فایل** دەگەڕێتەوە **+ کۆپی PDF یش** لەگەڵ دەنێردرێت. PDF ی سکانیکراویش (وێنەیی) خۆکارانە بە **OCR** دەخوێنرێتەوە.
- **ڤیدیۆ و دەنگ** — فایل بنێری یان **لینکی YouTube / Facebook / TikTok**: دەنگەکە دەخوێنرێتەوە (faster-whisper)، وەریدەگێڕدرێت و بە فایلی **SRT + Word + PDF** دەنێردرێت — **و ژێرنووسی کوردی ڕاستەوخۆ لەسەر ڤیدیۆکە دادەنرێت**.
- **دەنگی کوردی سۆرانی (ئارەزوومەندانە)** — دەتوانیت داوا بکەیت دەنگی ڤیدیۆکە بە قسەکردنی **کوردی سۆرانی** جێگۆڕکێ بکرێت (بە kurdishtts.com) — بە فەرمانی `/voice_on`.
- **بچووککردنەوەی خۆکار** — ئەگەر ڤیدیۆی ژێرنووسدار لە **٢٠ مێگابایت** گەورەتر بوو، خۆکارانە بۆ خوار ٢٠MB بچووک دەکرێتەوە؛ ئەگەر فایلەکە خۆی گەورەیە (تا ٢ گێگابایت)، بۆتەکە دەیگرت و پێش وەرگێڕان بچووکی دەکاتەوە.
- **ئەرشیڤی خۆکار لە GitHub** — هەر فایلێک بکرێت بۆ بۆتەکە (ڤیدیۆ / دۆکیومێنت / دەنگ)، هەمان فایل بە خۆکاری بۆ ڕیپۆکەت بار دەکرێت: تا **٩٥MB** بۆ **فۆڵدەری `data/`** (`video.mp4 → data/video.mp4`)، و **سەرووی ئەوە تا ٢GB** بۆ **Release ی `telegram-files`** — بێ هیچ ڕێکخستنێک، لەگەڵ ناوی نێرەر.

هەمووی **بەخۆڕایی**ە و **بێ سێرڤەر** کار دەکات: تەنها لە GitHub Actions، بە شێوەی **٢٤/٧ ئۆنلاین**، و تەواوی ڕێکخستنەکە دەکرێت تەنها بە **مۆبایل** بکرێت.

---

## چۆن کار دەکات؟ (کورتە)

1. بۆتەکە **٢٤ کاتژمێر لە ٧ ڕۆژ ئۆنلاینە**: هەر خولێک **٤٥ خولەک** بەردەوام پەیامەکان وەردەگرێت (long polling) و زۆر بە خێرایی وەڵام دەداتەوە.
2. لە کۆتایی هەر خولێک، خولێکی نوێ **خۆکارانە** دەست پێدەکات (زنجیرەی بێکۆتایی) — بۆیە بۆتەکە ناوەستێت. cron ی هەر ١٠ خولەک تەنها وەکو پاشەکەوت (backup) کار دەکات ئەگەر زنجیرەکە بپچڕێت.
3. شوێنی دوا پەیامی پرۆسێسکراو (offset) لە **cache** ی Actions پاشەکەوت دەکرێت، بۆیە هیچ پەیامێک دووبارە پرۆسێس ناکرێت.
4. **بزوێنەری وەرگێڕان بەردەوام و پتەوە**:
   - **گووگڵ Translate** بە **٣ ڕێڕەوی جیاواز** (translate.googleapis.com، clients5.google.com، translate.google.com — هەرکام بە POST و GET). ئەگەر ڕێڕەوێک بلۆک بوو (429)، خۆکارانە ڕێڕەوی دووەم و سێیەم تاقی دەکاتەوە.
   - **GLM/Z.ai** یەدەگە — بە **چەند مۆدێل** (glm-4.5-flash ی خۆڕایی، glm-4-flash، glm-4.5-air) و **دوو سێرڤەر** (api.z.ai و open.bigmodel.cn). تێکەڵەی سەرکەوتوو لەبەر دەکرێت.
   - **ئەگەر بەشێکی وەرگێڕان سەرنەچوو**، تەنها ئەو بەشە بە زمانی ڕەسەن دەمێنێتەوە و **پرۆسەکە بەردەوام دەبێت** — هەرگیز هەموو ئەنجامێک لەدەست ناچێت. ئەگەر وەرگێڕان بە تەواوی سەرنەچوو، **نووسینی ڕەسەن** بە فایل دەنێردرێت.
5. بۆ ڤیدیۆ/دەنگ: `yt-dlp` (لینک) یان فایلی تەلەگرام → بچووککردنەوە ئەگەر گەورەیە → `ffmpeg` → `faster-whisper` → وەرگێڕان → SRT + Word + PDF + **ڤیدیۆی ژێرنووسدار** (+ دەنگی کوردی ئەگەر چالاکە).
6. **داواکارییە هاوکاتەکان**: بۆتەکە لە یەک کاتدا **چەند داواکاری** وەردەگرێت — تا `MAX_CONCURRENT_JOBS` (بنەڕەت ٢) بە هاوکات جێبەجێ دەکرێن و ئەوانی تر بە ڕیز دادەنرێن و خۆکارانە جێبەجێ دەکرێن — هیچ کەس ناچار نییە چاوەڕوانی داواکاریی کەسی تر بێت.

- مۆبایل + ئینتەرنێت (هیچ کۆمپیوتەرێک پێویست نییە)
- هەژماری GitHub (بەخۆڕایی) — github.com
- هەژماری Telegram

---

## هەنگاو ١ — دروستکردنی بۆت لە BotFather (مۆبایل)

1. لە وێبگەڕی مۆبایل بکەرەوە: `web.telegram.org` و بچۆ ژوورەوە.
2. لە بەشی گەڕان بنووسە: `@BotFather` و چاتەکە بکەرەوە.
3. بنووسە: `/newbot`
4. ناوێک دابنێ بۆ بۆتەکە (بۆ نموونە: `Sorani Translator`).
5. دواتر username ێک دابنێ کە بە `bot` کۆتایی دێت (بۆ نموونە: `my_sorani_translator_bot`).
6. BotFather تۆکنێکت دەداتێ، وەکو: `123456789:AAF3xyz...`
7. ئەو تۆکنە کۆپی بکە و لە شوێنێکی پارێزراو هەڵیبگرە — لە هەنگاوی ٤ پێویستمان دەبێت.

## هەنگاو ٢ — دروستکردنی ڕیپۆ لە GitHub (مۆبایل)

1. لە وێبگەڕی مۆبایل: `github.com` بچۆ ژوورەوە (یان هەژمار دروست بکە).
2. کلیک لە ئایکۆنی **+** (سەرەوە، ڕاست) بکە → **New repository**.
3. ناوی ڕیپۆ: `sorani-translator-bot`
4. دڵنیابە کە **Public** هەڵبژێردراوە (گرنگە: بۆ ئەوەی GitHub Actions بەخۆڕایی و بێسنوور بێت).
5. کلیک بکە لە **Create repository**.

## هەنگاو ٣ — زیادکردنی سێ فایلەکە (مۆبایل)

سێ فایل پێویستە دروست بکەیت. بۆ هەر یەکێک لەمانە هەمان ڕێگا بەکارهێنە:

**فایلی ١ — `bot.py`:**

1. لە پەڕەی ڕیپۆکە، کلیک بکە لە **Add file** → **Create new file**.
2. لە خانەی ناوی فایل بنووسە: `bot.py`
3. ناوەڕۆکی فایلی `bot.py` کۆپی بکە و لەوێ paste بکە.
4. کلیک بکە لە **Commit changes**.

**فایلی ٢ — `requirements.txt`:** هەمان شێوە — ناوەکە بنووسە `requirements.txt` و ناوەڕۆکەکەی paste بکە.

**فایلی ٣ — `.github/workflows/bot.yml`:**

1. **Add file** → **Create new file**.
2. لە خانەی ناو بنووسە: `.github/workflows/bot.yml`
   (کاتێک `/` دەنووسیت، GitHub خۆکارانە فۆڵدەر دروست دەکات — ئەمە ئاساییە.)
3. ناوەڕۆکی فایلی `bot.yml` کۆپی بکە و paste بکە.
4. **Commit changes**.

**فایلی ٤ — `fonts/NotoNaskhArabic-Regular.ttf` (پێشنیارکراو):** بۆ ئەوەی ژێرنووسی سەر ڤیدیۆ **هەمیشە بە پیتە بەستراوەی دروست** دەربکەووە:

1. **Add file** → **Upload files**.
2. لە خانەی ناو بنووسە: `fonts/` (فۆڵدەر خۆکارانە دروست دەبێت).
3. فایلی `NotoNaskhArabic-Regular.ttf` لەناو فایلی ZIP ی پرۆژەکە هەڵبژێرە و بارکی بکە.
4. **Commit changes**.

> تێبینی: ئەگەر ئەم فایلە بار نەکەیت، بۆتەکە خۆی فۆنت لە سیستەم یان ئینتەرنێتەوە بەکاردەهێنێت — بەڵام بارکردنی بەباشترین دڵنیاییە و بێ ئینتەرنێتی زیادە کار دەکات.

تێبینی: دەتوانیت فایلەکان لە فایلی ZIP ی پرۆژەکەش وەربگریت و بە شێوەی تاک-تاک paste یان Upload بکەیت.

## هەنگاو ٤ — زیادکردنی تۆکن وەکو Secret (مۆبایل)

1. لە ڕیپۆکە: **Settings** → لە لای چەپ **Secrets and variables** → **Actions**.
2. کلیک: **New repository secret**
3. Name: `BOT_TOKEN`
4. Secret: تۆکنی BotFather کە لە هەنگاوی ١ کۆپیت کرد.
5. کلیک: **Add secret**

ئارەزوومەندانە (بەڵام زۆر بەسوود):

- `ZAI_API_KEY` — کلیلەکەی GLM/Z.ai بۆ وەرگێڕانی یەدەگ (ئەگەر گووگڵ بلۆک بوو).
- `KURDISH_TTS_API_KEY` — کلیلەکەی [kurdishtts.com/settings/api](https://www.kurdishtts.com/settings/api) بۆ **دەنگی کوردی سۆرانی** لەسەر ڤیدیۆ.
- `TG_API_ID` و `TG_API_HASH` — بۆ **فایلی گەورەتر لە ٢٠ مێگابایت** (بڕوانە بەشی خوارەوە).

## هەنگاو ٥ — چالاککردنی Actions و یەکەم کار

1. لە ڕیپۆکە بچۆ بۆ تابۆی **Actions**.
2. ئەگەر پەیامێک بوو: **I understand my workflows, go ahead and enable them** کلیک بکە.
3. لە لای چەپ کلیک بکە لە: **Sorani Translator Bot**
4. کلیک: **Run workflow** → دووبارە **Run workflow**
5. چاوەڕێ بکە دوگمەکەی بەوەی نیشانەی سەوز بێت (نزیکەی ٢-٤ خولەک).

لەو کاتەوە بۆتەکە خۆی خۆکارانە خولەکان بەردەوام دەکات — **پێویست ناکات هیچی دیکە بکەیت**.

## هەنگاو ٦ — تاقیکردنەوەی بۆتەکە

1. لە تەلەگرام، ناوی بۆتەکە بکەرەوە (ئەوەی لە BotFather دروستت کرد).
2. بنووسە: `/start` — پەیامی بەخێرهاتن دەبینیت.
3. دەقێکی ئینگلیزی بنێرە → وەرگێڕدراوی سۆرانی وەردەگریت.
4. فایلی Word بنێرە → **Word ی وەرگێڕدراو + کۆپی PDF** وەردەگریت.
5. ڤیدیۆیەک بە فایل بنێرە → **SRT + Word + PDF + ڤیدیۆکە بە ژێرنووسی کوردی** وەردەگریت.
6. بنووسە `/voice_on` → لە ڤیدیۆی داهاتوودا **دەنگی کوردی سۆرانی**ش لەسەر ڤیدیۆکە دادەنرێت.

## تایبەتمەندییەکان بە وردی

### ژێرنووسی لەسەر ڤیدیۆ (burn-in)

کاتێک ڤیدیۆیەک دەنێری (فایل یان لینک)، دوای وەرگێڕان بۆتەکە هەمان ڤیدیۆ بە **ژێرنووسی کوردی لەسەر وێنەکە** بۆت دەنێرێتەوە — بە فۆنتی جوانی کوردی (Noto Naskh Arabic / Amiri)، لە خوارەوەی ڤیدیۆکەوە، سپی بە پەراوێزی ڕەش.

**دڵنیابە لە پیتە بەستراوەکان:** فۆنتی کوردی لەگەڵ بۆتەکە خۆی بار دەکرێت (فۆڵدەری `fonts/`)، و بۆتەکە ناوی ڕاستەقینەی فۆنت لە ناو فایلەکەوە دەخوێنێتەوە و بە فۆرماتی ASS ژێرنووسەکە دەسووتێنێت — بەمەش پیتە کوردییەکان (ڕ ڵ ۆ ێ ە گ چ پ ژ ڤ) **هەمیشە بە دروستی بەستراوە و لە ڕاستەوە بۆ چەپ** دەردەکەون، تەنانەت ئەگەر فۆنتی سیستەم نەبێت.

- **هاوکاتکردنی کات (word-level sync):** بۆتەکە کاتی **هەر وشەیەک** لە ڤیدیۆکە پێوانە دەکات (word timestamps) — بۆیە هەر ژێرنووسێکی کوردی ڕێک لە **هەمان چرکەی** قسەکردنی ڕەسەن دەردەکەوێت (نموونە: لە چرکەی ٢٠ "Hello" گوترێت → وەرگێڕانەکەی لە چرکەی ٢٠ دەردەکەوێت). پچڕانی ژێرنووس لە پشووی سروشتی قسەکردن و کۆتایی ڕستەکان دادەنرێت — تەنانەت ئەگەر Whisper هەموو ڤیدیۆکە بە یەک بەش بناسێنێتەوەش، کاتەکان ورد دەمێننەوە.
- ئەگەر ڤیدیۆکە لە `BURN_MAX_MINUTES` (بنەڕەت ٣٠ خولەک) درێژتر بێت، فایلی SRT دەنێردرێت بەبێ سووتاندن.
- دەنگی خاڵیس (بێ وێنە) سووتاندنی لەسەری ناکرێت — تەنها SRT + Word + PDF.
- ژێرنووسی درێژ خۆکارانە **دەکات بە چەند بەشی بچووکتر** (تا ٩٥ پیت) — خوێندنئاسانترە و وەرگێڕانی متمانەبەخۆترە.
- **قەبارە**: ئەگەر ڤیدیۆی ژێرنووسدار لە `OUT_VIDEO_MAX_MB` (بنەڕەت **٢٠ مێگابایت**) گەورەتر بوو، خۆکارانە بە دوو-پاس بۆ خوار ئەو قەبارە بچووک دەکرێتەوە.
- فایلەکانی SRT و Word و PDF **هەموو کات** پێش ڤیدیۆکە دەنێردرێن — تەنانەت ئەگەر سووتاندن سەرنەچووبێت.

### داواکارییە هاوکاتەکان (چەند کەس بە یەک کات)

پێشتر کاتێک یەک ڤیدیۆ پڕۆسێس دەکرا، داواکاریی کەسانی تر تا تەواوبوونی ئەو وەڵام نەدەدرایەوە. ئێستا بۆتەکە **چەند کرێکاری هاوکات** بەکاردەهێنێت:

- **تا ٢ داواکاری بە هاوکات جێبەجێ دەکرێن** (`MAX_CONCURRENT_JOBS`، بنەڕەت ٢) — بۆ نموونە دوو ڤیدیۆ پێکەوە.
- **داواکاریی زیاتر لە ڕیزدا دادەنرێت**: بەکارهێنەر یەکسەر پەیامی «داواکارییەکەتان وەرگیرا — ئێستا N داواکاری تر لەپێشتانن لە ڕیزدا» وەردەگرێت، و خۆکارانە دوای تەواوبوونی ئەوان دەست پێدەکات.
- **مۆدێلی Whisper بە چەند worker کاردەکات** — بۆیە دوو ڤیدیۆ پێکەوە ناسینەوەی دەنگیان بۆ دەکرێت.
- ئەگەر ڕیزەکە پڕ بوو (بنەڕەت ٨ — `MAX_QUEUE`)، بەکارهێنەر پەیامی «دواتر هەوڵ بدەوە» وەردەگرێت — بۆ ئەوەی ڕیپۆکە بە داواکاری زۆر نەخنکێت.
- لە کۆتایی هەر خولێک، بۆتەکە چاوەڕوانی داواکارییە ماوەکان دەبێت پێش داخستن — هیچ ئەنجامێک لەدەست ناچێت.
- **تێبینی**: لەسەر runner ی خۆڕایی GitHub (٢ کرێدار) باشترە ٢ بمێنێتەوە؛ ئەگەر ڕیپۆکە **Public**ـە (٤ vCPU) دەتوانیت بیکەیتە ٣.

### پاشەکەوتی خۆکاری فایلەکان لە ڕیپۆکەت (data/ + Release)

هەر کەسێک فایلێک بنێرێت بۆ بۆتەکە (ڤیدیۆ، Word، PDF، دەنگ...)، **هەمان فایل بە خۆکاری** بۆ ڕیپۆی خۆت بار دەکرێت — بەپێی قەبارەکەی لە دوو شوێن:

| بنێرە بۆ بۆت | لە GitHub دا دەبینیت |
|---|---|
| `video.mp4` (٤٠MB) | `data/video.mp4` |
| `document.pdf` (٢MB) | `data/document.pdf` |
| دەنگ / voice | `data/voice.oga` |
| `movie.mp4` (٥٠٠MB) | **Releases → `telegram-files` → `movie.mp4`** |

- **بۆچی دوو شوێن؟** GitHub بۆ فۆڵدەری ڕیپۆ فایلی سەرو **١٠٠ مێگابایت** بلۆک دەکات (سنووری خۆی GitHub ە) — بۆیە فایلە گەورەکان دەچنە بەشی **Releases** کە تا **٢GB** بۆ هەر فایلێک قبوڵ دەکات و خۆڕاییە.

- **هیچ ڕێکخستنێک پێویست نییە** — `bot.yml` ی نوێ تۆکنی `github.token` ی خۆی بەکاردەهێنێت و ڕێپێدانی `contents: write` ی داوە. تەنها دڵنیابە هەردوو فایلی `bot.py` و `bot.yml` نوێن.
- لە **نامەی commit** ەکەدا ناوی نێرەر دەبینیت: `data: video.mp4 from Ahmed (id 12345)` — بۆیە دەزانیت کێ چی ناردووە.
- **ئەگەر ناوی هەمان دووبارە بێتەوە**: خۆکارانە تایمستامپ زیاد دەکرێت — `data/video_20261025-143022.mp4` (هیچ فایلێک ناسڕدرێتەوە).
- بارکردنەکە لە **پاشبنەما**دا دەکرێت — وەرگێڕان چاوەڕوانی نابێت، و ئەگەر بارکردن بە هەر هۆکارێک شکستی هێنا، هیچ کاریگەری لەسەر وەرگێڕان نییە (تەنها لۆگ دەبن).
- **سنووری قەبارە**: تا **٩٥ مێگابایت** → فۆڵدەری `data/` (سنووری Contents API ی GitHub: ١٠٠MB)؛ **سەروی ئەوە تا ٢GB** → ئەسێتی ڕلیز لە `Releases → telegram-files`. سەرو ٢GB? تەلەگرام خۆی ڕی دەگرێت (سنووری ناردن بۆ بۆت ٢GB یە).
- **بۆ فایلە گەورەکان (ڕلیز)**: کاتێک یەکەم فایلی گەورە دەگات، ڕلیزەکە خۆکارانە دروست دەکرێت. ناوی نێرەر + کات + قەبارەی هەر فایلێک دەچێتە ناو وەسفی ڕلیزەکەوە، و لە لۆگی Actions ش دەبینیت (`github archive OK (release ...)`).
- تەنها فایلە ڕاستەوخۆکان ئەرشیڤ دەکرێن — ڤیدیۆی لینکی (YouTube / TikTok / Facebook) ئەرشیڤ ناکرێت.
- **قەبارەی ڕیپۆکە لەگەڵ کات گەورە دەبێت** — فایلەکانی `data/` لە مێژووی git دا دەمێننەوە تەنانەت دوای سڕینەوە. فایلەکانی ڕلیز کاریگەریان لەسەر قەبارەی ڕیپۆ نییە. ئەگەر ڕیپۆکە زۆر گەورە بوو، فۆڵدەری `data/` بە دەستی پاک بکەوە یان ڕیپۆی نوێ دەست پێ بکە.

**ناچالاککردن:** variable ی `GH_UPLOAD` بکە بە `0` (Settings → Secrets and variables → Actions → Variables).

### دەنگی کوردی سۆرانی لەسەر ڤیدیۆ (TTS) — ئارەزوومەندانە

بۆتەکە دەتوانێت دەنگی ڤیدیۆکە بگۆڕێت بۆ **قسەکردنی کوردی سۆرانی** — هەر ژێرنووسێک لە کاتی خۆی قسە دەکرێت (بە خزمەتگوزاری [kurdishtts.com](https://www.kurdishtts.com)).

**هاوکاتی تەواو لەگەڵ ڤیدیۆ:** هەر ڕستەیەکی کوردی ڕێک لە **هەمان چرکەی** ڕستە ڕەسەنەکە دەست پێدەکات — واتە ئەگەر لە چرکەی ٢٠ وشەیەک لە ڤیدیۆکە بگوترێت، وەرگێڕانە کوردییەکەشی لە هەمان چرکە دەگات. ئەگەر ڕستەیەکی کوردی درێژتر بوو لە مەوداکەی، خۆکارانە کەمێک خێراتر دەکرێت (تا ٢.٥x) یان لە کۆتایی مەوداکە دەبڕدرێت — بۆ ئەوەی هەرگیز لەسەر ڕستەی داهاتوو نەکەوێت و هاوکاتەکە تێک نەچێت.

**چۆن چالاکی بکەم؟**

1. لە `kurdishtts.com` هەژمار دروست بکە (بەخۆڕایی: **٢٠,٠٠٠ پیت بۆ مانگێک**).
2. بچۆ بۆ **Settings → API** و **TTS API Key** دروست بکە.
3. لە GitHub: **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `KURDISH_TTS_API_KEY`
   - Secret: کلیلەکە
4. لە تەلەگرام بنووسە: `/voice_on`

**فەرمانەکان:**

| فەرمان | کاری دەکات |
|---|---|
| `/voice_on` (یان `/deng_on`) | دەنگی کوردی چالاک دەکات — لە ڤیدیۆی داهاتوودا دەنگی سۆرانی جێگۆڕی ڕەسەن دەبێت |
| `/voice_off` (یان `/deng_off`) | ناچالاکی دەکات — ڤیدیۆ بە دەنگی ڕەسەنی خۆی دەمێنێتەوە |
| `/voice` (یان `/deng`) | پیشاندانی دۆخی ئێستا |

- دەنگی بنەڕەت: `sorani_85` (خۆڕایی). بۆ گۆڕین: variable ی `TTS_SPEAKER_ID` (بۆ نموونە `sorani_214`).
- ئەگەر پیتەکان تەواو بوون یان کلیل نەبوو، ڤیدیۆ بە دەنگی ڕەسەن نێردرێتەوە و پەیامێکت بۆ دێت.
- `TTS_MAX_CHARS` (بنەڕەت ١٥٠٠٠) سنووری پیت بۆ هەر ڤیدیۆیەکە — بۆ پاراستنی سەقەتی مانگانە.

### فایلی گەورەتر لە ٢٠ مێگابایت (تا ٢ گێگابایت)

تەلەگرام بۆتەکان ناهێڵێت فایلی لە ٢٠ مێگابایت گەورەتر دابگرێت — **بەڵام چارەسەر هەیە**: سێرڤەری ناوخۆیی Bot API.

**چۆن چالاکی بکەم؟ (مۆبایل)**

1. بچۆ بۆ `my.telegram.org` → چوونەژوورەوە بە ژمارە مۆبایلییەکەت.
2. کلیک بکە لە **API development tools** → فۆرمەکە پڕ بکەوە (ناوی ئارەزوومەندانە، Platform: Desktop).
3. دوو شت دەداتێ: **api_id** (ژمارە) و **api_hash** (دەقێکی درێژ) — هەردووکیان کۆپی بکە.
4. لە GitHub: **Settings → Secrets and variables → Actions** دوو secret زیاد بکە:
   - Name: `TG_API_ID` → Secret: ژمارەکە
   - Name: `TG_API_HASH` → Secret: دەقەکە

لە خولی داهاتوودا بۆتەکە خۆکارانە سێرڤەرەکە لە GitHub Actions دادەمەزرێنێت (docker):

- **داگرتن تا ٢ گێگابایت** — ڤیدیۆی گەورە بنێرە بێ کێشە.
- **بچووککردنەوەی خۆکار**: ڤیدیۆی گەورە (لە `SHRINK_OVER_MB` زیاتر یان بەرزی > 720p) پێش وەرگێڕان بۆ 720p بچووک دەکرێتەوە — خێراتر و سووکتر.
- ئەنجامی کۆتایی هەر لە خوار ٢٠ مێگابایتە (`OUT_VIDEO_MAX_MB`).
- ئەگەر ئەم دوو secret ێکە دانەنران، هیچ کێشەیەک نییە — تەنها سنووری ٢٠ مێگابایت دەمێنێتەوە و بۆتەکە ڕێنمایی دەکات.

### کۆپی PDF بۆ هەموو فایلەکان

هەر فایلێک بنێری، لەگەڵ فایلی وەرگێڕدراوی **هەمان جۆر**، **کۆپی PDF یش** وەردەگریت:

| بنێرە | وەردەگریت |
|---|---|
| Word (docx) | **Word ی وەرگێڕدراو** + **PDF** (بە LibreOffice — هەمان شێواز و وێنەکان) |
| PowerPoint (pptx) | **PPTX ی وەرگێڕدراو** + **PDF** (هەمان سلایدەکان) |
| TXT | **TXT ی وەرگێڕدراو** + PDF ی ساکاری RTL |
| SRT | **SRT ی وەرگێڕدراو** (کاتەکان وەکو خۆیان) + PDF ی نووسین |
| PDF (نووسراو) | PDF ی وەرگێڕدراو بە ڕیزبەندی RTL |
| PDF (سکانیکراو/وێنەیی) | **خۆکارانە OCR دەکرێت** (tesseract: عەرەبی+ئینگلیزی) و پاشان وەرگێڕدراوەکە بە PDF ی RTL دێتەوە |

ئەگەر بە هەر هۆکارێک LibreOffice بەردەست نەبوو، خۆکارانە بە ReportLab بە شێوازی ساکار و ڕاست-بۆ-چەپ دروست دەکرێت — هەرگیز بێ PDF نامێنێت.

## ڕێکخستنە ئارەزوومەندانەکان

ئەمانە دەکرێت وەکو **variable** یان بە ڕاستەوخۆ دەستکاریکردنی `bot.yml` ڕێکبخرێن (Settings → Secrets and variables → Actions → Variables):

| ناو | بنەڕەت | واتا |
|---|---|---|
| `WHISPER_MODEL` | `base` | مۆدێلی ناسینەوەی دەنگ: `tiny` (خێراترین) / `base` / `small` (وردتر) |
| `MAX_VIDEO_MINUTES` | `0` | سنووری درێژی ڤیدیۆ بە خولەک. `0` = بێ سنوور |
| `MAX_CONCURRENT_JOBS` | `2` | چەند داواکاری بە هاوکات جێبەجێ بکرێت (٢ بۆ runner ی ٢-کرێدار؛ ٣ بۆ repo ی گشتی) |
| `MAX_QUEUE` | `8` | زۆرترین ڕیزی چاوەڕوانی — پاش ئەوە پەیامی «ڕیزەکە پڕە» دەنێردرێت. `0` = بێ ڕیز |
| `BURN_SUBTITLES` | `1` | `1` = ژێرنووسی کوردی لەسەر ڤیدیۆ دادەنرێت. `0` = ناکرێت |
| `BURN_MAX_MINUTES` | `30` | زۆرترین درێژی ڤیدیۆ بۆ سووتاندنی ژێرنووس (بە خولەک) |
| `SEND_PDF_COPY` | `1` | `1` = کۆپی PDF بۆ هەموو فایلەکان دەنێردرێت. `0` = نانێردرێت |
| `OUT_VIDEO_MAX_MB` | `20` | ڤیدیۆی ژێرنووسدار بۆ خوار ئەم قەبارە بچووک دەکرێتەوە |
| `SHRINK_OVER_MB` | `60` | ڤیدیۆی گەورەتر لەمە پێش پرۆسێسکردن بۆ 720p بچووک دەکرێتەوە |
| `TTS_SPEAKER_ID` | `sorani_85` | دەنگی کوردی (خۆڕایی: `sorani_85` یان `sorani_214`) |
| `TTS_SPEED` | `1.0` | خێرایی قسەکردن (٠.٢٥ تا ٤) |
| `TTS_MAX_CHARS` | `15000` | زۆرترین پیت بۆ دەنگی هەر ڤیدیۆیەک (سەقەتی پلانی خۆڕایی) |
| `SOURCE_LANG` | بەتاڵ | زمانی سەرچاوەی دەنگ بە زۆر (بۆ نموونە `en`). بەتاڵ = خۆکار |
| `TARGET_LANG` | `ckb` | زمانی ئامانج (`ckb` = سۆرانی) |
| `YT_CLIENTS` | `default,android_vr,web_safari,tv,web_embedded` | زنجیرەی کلیێنتەکانی yt-dlp بۆ داگرتنی لینک — یەکەم دانەی سەرکەوتوو بەکار دەهێنرێت |
| `GH_UPLOAD` | `1` | `1` = فایلە وەرگیراوەکان بۆ فۆڵدەری `data/` ی ڕیپۆ بار دەکرێن (ئەرشیڤ). `0` = ناچالاک |
| `GH_UPLOAD_DIR` | `data` | فۆڵدەری ئەرشیڤ لە ڕیپۆکەت |
| `GH_UPLOAD_BRANCH` | بەتاڵ | لقی بارکردنی ئەرشیڤ — بەتاڵ = لقی workflow ەکە (بنەڕەت) |
| `GH_UPLOAD_MAX_MB` | `95` | سنووری فۆڵدەری `data/` (زۆرترین ١٠٠ — سنووری GitHub) — `0` = بێ پشکنین؛ فایلی سەرو ئەم سنوورە تا ٢GB خۆکارانە دەچێتە ڕلیز |
| `GH_UPLOAD_RELEASE_TAG` | `telegram-files` | ناوی ڕلیز (Releases) کە فایلە گەورەکان (سەرو ٩٥MB تا ٢GB) بۆ بار دەکرێن |

**Secrets** (پارێزراوتر — تەنها لە Secrets دابنێ):

| ناو | پێویست؟ | واتا |
|---|---|---|
| `BOT_TOKEN` | بەڵێ، پێویستە | تۆکنی بۆت لە BotFather |
| `ZAI_API_KEY` | نەخێر | کلیلەکەی GLM/Z.ai بۆ وەرگێڕانی یەدەگ |
| `KURDISH_TTS_API_KEY` | نەخێر | کلیلەکەی kurdishtts.com بۆ دەنگی کوردی سۆرانی |
| `TG_API_ID` | نەخێر | لە my.telegram.org — بۆ فایلی تا ٢ گێگابایت |
| `TG_API_HASH` | نەخێر | لە my.telegram.org — بۆ فایلی تا ٢ گێگابایت |
| `YT_COOKIES` | نەخێر | کوکییەکانی وێبگەڕ بۆ YouTube (کاتێک بلۆک دەبێت) |

**چۆن YT_COOKIES بەدەست بهێنم؟** (تەنها ئەگەر YouTube لینکەکان fail دەکات)

1. لە کۆمپیوتەرێک (ی مۆبایل بە ئامرازی ytdlp) چوونەژوورەوە بۆ YouTube بکە.
2. زیادکراوێکی وەکو "Get cookies.txt LOCALLY" لە کڕۆم بەکاربهێنە و فایلی cookies.txt دابگرە.
3. ناوەڕۆکەکەی کۆپی بکە و وەکو secret ی `YT_COOKIES` دابنێ.

## سنوورەکان و شتەکانی پێویست بزانیت

- **بەبێ TG_API_ID/TG_API_HASH**: فایلی ڕاستەوخۆ تا ٢٠ مێگابایت (سنووری تەلەگرام بۆ بۆتەکان) — لەگەڵیان: تا **٢ گێگابایت**.
- **تێبینی گرنگ بۆ سێرڤەری ناوخۆیی** — وێنە نوێیەکەی `aiogram/telegram-bot-api` (Docker) ئیتر پارامەترەکانی دێڕی فەرمان وەکو `--local` ناناسێت و تەنها `env` دەخوێنێت. بۆیە `bot.yml` ی نوێ `-e TELEGRAM_LOCAL=1` دەنێرێت — بەبێ ئەوە فایلی سەرو ٢٠ مێگابایت دادەگرێت. ئەگەر bot.yml ی کۆن هێشتا بەکاردەهێنیت، ئەمە خۆیەتی هۆکاری هەڵەی «file is too big».
- **YouTube** — زۆرجار ئایپییەکانی GitHub Actions بلۆک دەکات. بۆتەکە ئێستا **٥ کلیێنتی جیاواز × ٢ خول** تاقی دەکاتەوە: خولی یەکەم بە فۆرماتی ڤیدیۆ (`default` → `android_vr` → `web_safari` → `tv` → `web_embedded`)، ئەگەر یووتیوب فۆرماتەکانی داخست (SABR/PO Token)، خولی دووەم **تەنها دەنگ** دەگرێت — SRT و Word و PDF هێشتا بە تەواوی دەنێردرێن (تەنها ژێرنووس لەسەر ڤیدیۆ ناکرێت و بۆت ئاگاداری دەکات). چارەسەری تەواو: `YT_COOKIES`.
- **PDF** — PDF ی سکانیکراو خۆکارانە OCR دەکرێت (تا ٤٠ پەڕە)؛ ئەگەر OCR شکستی هێنا (کوالیتی وێنە زۆر لاوازە)، پەیامێکی ڕوون دەیتێ. PDF ی سەرەتایی بە شێوازی ساکار RTL ڕێکدەخرێتەوە؛ کۆپی PDF ی Word/PowerPoint بە LibreOffice شێواز و وێنەکان دەپارێزێت.
- **ناسینەوەی دەنگی سۆرانی** — Whisper بۆ زمانە گەورەکان (ئینگلیزی، عەرەبی، تورکی...) زۆر باشە، بەڵام بۆ دەنگی سۆرانی لاوازە (دەتوانیت STT ی kurdishtts.com بە دەستی بەکاربهێنیت).
- **کاتی کارکردن** — هەر خولێک ٤٥ خولەکە؛ ڤیدیۆی زۆر زۆر درێژ (چەند کاتژمێر) گونجاو نییە. دەتوانیت بە `MAX_VIDEO_MINUTES` سنووری دابنێیت.
- **دوای ٦٠ ڕۆژ** — ئەگەر هیچ commit ێک لە ڕیپۆ نەکرێت، GitHub تەنها **cron** ی پاشەکەوت ناچالاک دەکات — بەڵام زنجیرەی سەرەکی (خۆ-دووبارەکردنەوە) بەردەوام دەبێت و بۆتەکە ئۆنلاین دەمێنێت.
- **تۆکنەکان پارێزراون** — لە ڕیپۆی Public دا هەموو کلیلەکان تەنها لە Secrets دان و هیچ کەس نایبینێت.

## خەرجی

- ڕیپۆی **Public**: GitHub Actions **بەخۆڕایی و بێسنوور**ە.
- خاڵی وەرگێڕانی گووگڵ: بەخۆڕایی.
- GLM/Z.ai: ئارەزوومەندانە (بەپێی پلانەکەت).
- kurdishtts.com: پلانی خۆڕایی **٢٠,٠٠٠ پیت/مانگ** بۆ دەنگی کوردی.

## چارەسەری کێشە

**«وەرگێڕان سەرنەچوو — گووگڵ و GLM هەردووکیان وەڵام نەدانەوە»؟**

1. دووبارە پەیامەکە بنێرە — بە زۆری هەوڵی دووەم سەرکەوتوو دەبێت (ئێستا ٣ ڕێڕەوی گووگڵ + ٦ تێکەڵەی GLM هەیە).
2. ئەگەر بەردەوام بوو: دڵنیابە secret ی `ZAI_API_KEY` دانراوە و کلیلەکە دروستە.
3. تێبینی بکە: ئەگەر تەنها **بەشێکی** وەرگێڕان سەرنەچووبێت، ئەو بەشە بە زمانی ڕەسەن دەمێنێتەوە و ئەنجامەکە بەردەوام دەنێردرێت.
4. ئەگەر وەرگێڕان بە تەواوی سەرنەچوو، **نووسینی ڕەسەن** وەکو فایل دەنێردرێت — هیچ لەدەست ناچێت.

**«نەتوانم ڤیدیۆکە لەم لینکە دابگرم»؟**

1. دووبارە هەوڵ بدە — بۆتەکە هەر جار **٥ کلیێنت × ٢ خول** تاقی دەکاتەوە (ڤیدیۆ، پاشان تەنها دەنگ) و پەیامی هەڵەکە هۆکارەکە ڕوون دەکاتەوە (پشکنینی مرۆیی / SABR / تایبەت / Geo-block / پەخشی ڕاستەوخۆ / Rate limit...).
2. ئەگەر هۆکارەکە «فۆرماتەکان داخستووە (SABR)» بوو: ئەمە خۆیەتی کاتێک یووتیوب فۆرماتە داگرتنییەکان بۆ ئایپی سێرڤەرەکان نادەیت — خولی دووەم تەنها دەنگ دەگرێت و **SRT و Word و PDF هێشتا بە تەواوی دەنێردرێن**؛ بۆ ڤیدیۆی ژێرنووسدار secret ی `YT_COOKIES` دابنێ.
3. ئەگەر هۆکارەکە «پشکنینی مرۆیی» بوو: secret ی `YT_COOKIES` دابنێ (ڕێنمایی لە سەرەوە) — ئەمە بەتەواوی کێشەکە چارەسەر دەکات.
4. لە زۆر حاڵەتدا `android_vr` / `tv` / `web_embedded` (کلیێنتەکانی بێ PO Token) بێ cookies کار دەکەن — بۆیە پێشتر هەوڵی دووبارە بدەوە.
5. بۆ TikTok/Facebook: هەندێک ڤیدیۆ چوونەژوورەوە دەوێت یان لە سێرڤەرەکان قەدەغەن — لەوانەیە تەنها بە فایل بگیرێن.

**بۆتەکە وەڵام ناداتەوە؟**

1. تابۆی Actions بکەرەوە — ئایا خولەکان جێبەجێ دەبن و سەوزن؟ (خولی درێژ = ئاساییە)
2. ئەگەر سوور (سەرکەوتوو نەبوو) بوون: لەسەر run ێک کلیک بکە و لۆگەکە بخوێنە.
3. `BOT_TOKEN` ڕاستە؟ دڵنیابە secret ێک بە ناوی دروست دانراوە.
4. دڵنیابە هەر چوار فایلەکە لە شوێنی دروستدان: `bot.py` و `requirements.txt` لە ڕەگی ڕیپۆ، و `.github/workflows/bot.yml` و `fonts/NotoNaskhArabic-Regular.ttf` لەناو فۆڵدەرەکان.

**ژێرنووسی لەسەر ڤیدیۆ نەکرا؟**

- ئەگەر ڤیدیۆکە لە ٣٠ خولەک درێژتر بێت، تەنها SRT دەنێردرێت — دەتوانیت بە variable ی `BURN_MAX_MINUTES` سنوورەکە گەورەتر بکەیت.
- فایلەکانی SRT و Word و PDF **هەموو کات** دەنێردرێن — تەنانەت ئەگەر سووتاندن سەرنەچووبێت. دووبارە هەوڵ بدە یان ڤیدیۆکە بچووکتر بکە.

**پیتەکانی ژێرنووسی سەر ڤیدیۆ جیاوەن / بە دروستی نانووسرێن؟**

- دڵنیابە فایلی `fonts/NotoNaskhArabic-Regular.ttf` لە ڕیپۆکە هەیە (فۆڵدەری `fonts/`) — ئەمە باشترین چارەسەرە.
- بۆتەکە ئێستا ناوی ڕاستەقینەی فۆنت لە ناو فایلەکەوە دەخوێنێت (fontTools) و بە فۆرماتی ASS دەسووتێنێت — ئەگەر فۆنتی نێو ڕیپۆ نەبوو، لە سیستەم یان ئینتەرنێتەوە دەیگرێت و هەر بە دروستی دەینووسێت.

**دەنگی کوردی کار ناکات؟**

- secret ی `KURDISH_TTS_API_KEY` دانراوە؟ `/voice` بۆ زانینی دۆخ بنێرە.
- پیتەکانی پلانی خۆڕایی تەواو بوون؟ لە kurdishtts.com/settings/api بڕوانە (٢٠,٠٠٠ پیت/مانگ).
- ڤیدیۆی زۆر درێژ (> `BURN_MAX_MINUTES`) دەنگی لەسەر نادەنێت.

**پشکنینی ژینگە:** لە `bot.yml` دا دەتوانیت step ێک زیاد بکەیت بە فەرمانی `python bot.py --check` — دەرهێنەکە دەڵێت کام بەش باشە (هەر ٣ ڕێڕەوی گووگڵ، GLM، ffmpeg، LibreOffice، tesseract، whisper، TTS...).

**هەڵەی 409 Conflict** — واتە دوو پرۆسە هاوکات getUpdates دەکەن. تەنها یەک شێوەی کارکردن چالاک بکە (یان Actions، یان لۆکاڵ). لە Actions دا concurrency خۆی ئەمە ڕادەگرێت.

**هەڵەی 404 لە کاتی ناردنی ڤیدیۆی گەورە (سێرڤەری ناوخۆیی Bot API)؟**

- ئەمە کێشەیەکی ناسراوی سێرڤەری `telegram-bot-api` ە (tdlib issue #742): `getFile` سەرکەوتووە بەڵام داگرتنی HTTP ی فایل 404 دەداتەوە.
- بۆتەکە ئێستا **چوار ڕێگای** بۆ داگرتن هەیە و خۆکارانە بەکاریان دەهێنێت: ① خوێندنەوەی ڕاستەوخۆ لە دیسکەوە (mount ی `tgdata`)، ② HTTP لەگەڵ ٣ هەوڵی دووبارە، ③ پاشەکەوتی فەرمی `api.telegram.org` بۆ فایلی ≤ ٢٠MB، ④ نامەی هەڵەی ڕوون.
- **پێویستە هەردوو فایلەکە نوێ بکەیتەوە**: `bot.py` **و** `.github/workflows/bot.yml` — لە bot.yml ی نوێ فۆڵدەری `tgdata` بۆ داتای سێرڤەرەکە دەبەسترێت (`-v tgdata:/var/lib/telegram-bot-api`) و `TG_DATA_DIR` دان دەنرێت، بۆیە فایلەکان ڕاستەوخۆ لە دیسکەوە دەخوێنرێنەوە و کێشەی 404 نامێنێت.

**هەڵەی «فایلەکە لە ٢ گێگابایت گەورەترە» بۆ فایلێک کە لەژێر ٢ گێگابایتە؟**

1. ئەمە پێشتر هەڵەیەکی گومڕاکەر بوو: سێرڤەری ناوخۆیی Bot API لە دۆخی local کار نەدەکرد و `getFile` بۆ فایلی سەرو ٢٠ مێگابایت «file is too big» دەدا و بۆتەکە بە هەڵە دەیوت فایلەکە > ٢ گێگابایتە.
2. هۆکارەکە: وێنە نوێیەکەی `aiogram/telegram-bot-api` پارامەتری `--local` لە دێڕی فەرمانەکە پشتگوێ دەخات (entrypoint ی نوێ تەنها env دەناسێت).
3. چارەسەر: **bot.yml ی نوێ** باربکە (وەشانی نوێ `-e TELEGRAM_LOCAL=1` دەنێرێت بۆ سێرڤەرەکە) و پاشان فایلەکە دووبارە بنێرەوە. وەشانی نوێی بۆتەکە هەروەها ئێستا نامەی هەڵە ڕاستگۆ دەدات و جیاوازی دەکات لەنێوان «فایل بەڕاستی > ٢ گێگابایتە» و «سێرڤەر لە دۆخی local نییە».

**فایلەکان بۆ فۆڵدەری `data/` بار نەبوون؟**

1. دڵنیابە **هەردوو فایلی** `bot.py` و `.github/workflows/bot.yml` نوێن — bot.yml ی نوێ `contents: write` و `GH_UPLOAD_TOKEN` ی تێدایە (بەبێ ئەوان بارکردن ناکرێت).
2. بزانە variable ی `GH_UPLOAD` بە `0` دانەنراوە.
3. **فایلی سەرو ٩٥ مێگابایت** ناچێتە `data/` — ئەمە سنووری خۆی GitHub ە (١٠٠ مێگابایت). ئەو فایلانە دەچنە **Releases → `telegram-files`** (تا ٢GB) — لەوێ دیریان بکەوە.
4. ئەگەر فایلی گەورە بۆ ڕلیز بار نەبوو، لۆگ بکەوە — دەستی پێدەکات بە `github release`. زۆرترین هۆکار: ڕیپۆکە **Private** ـە و تۆکن ڕێپێدانی نییە، یان ئینتەرنێتی runner ـە. بیرت نەچێت: بارکردن تەنها ئەرشیڤە و **هەرگیز** لەسەر وەرگێڕان کاریگەری نییە.
5. تێبینی: تەنها فایلە ڕاستەوخۆکان ئەرشیڤ دەکرێن — ڤیدیۆی لینکی (YouTube/TikTok/Facebook) ئەرشیڤ ناکرێت.

**دەمەوێت لۆکاڵی یان سێرڤەرێک بەکاری بهێنم؟** — بۆتەکە ئاسایی Python ە: `pip install -r requirements.txt` پاشان `BOT_TOKEN=xxx python bot.py` — بەبێ Actions بۆ ٤٥ خولەک polling دەکات؛ بۆ کارکردنی بێکۆتایی `RUN_SECONDS` گەورە بکە یان لۆپەکە دەستکاری بکە.

**پەیامێک دووبارە وەڵامدرایەوە؟** — دەگەرخە (cache) ی offset لەدەستچووە؛ ڕوودانی دەگەژە.
